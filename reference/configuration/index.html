    Configuration reference¶

    blinds¶

    Field Type Default Range Meaning
    entity entity id required cover.* The cover this entry controls.
    facade_azimuth degrees none 0–360 Compass direction the window's outside faces.
    has_tilt bool true Whether the cover has a tilt channel.
    slat_depth mm none Slat width front to back, needed only by slat_angle values.
    slat_distance mm none Spacing between slats, needed only by slat_angle values.
    tilt_after_arrival bool true Send tilt only after the position move finishes.
    tolerance degrees 45 0–180 (UI) How far either side of the facade the sun still counts as hitting it. YAML takes any number; 0 never matches, 180 or more always does.
    travel_time seconds 60 > 0 Time for a full run, used to wait for arrival before tilting.

    zones¶

    Field Type Default Range Meaning
    members list of entity ids none The blinds decided together as this zone.
    occupants list of person names none Person names read by the event_targets_zone condition (see conditions).

    values (entity)¶

    Field Type Default Range Meaning
    default integer required 0–100 Used when the entity is missing or not a number.
    entity entity id required input_number.* The helper entity read at decision time.
    type enum entity entity or slat_angle Picks this shape -- a value read from a helper entity.

    values (type: slat_angle)¶

    Field Type Default Range Meaning
    azimuth_attribute attribute name none Attribute to read the azimuth from, if it is not the entity's state.
    azimuth_entity entity id sensor.sun_solar_azimuth Entity the sun's azimuth is read from.
    default integer required 0–100 Used when the sun is down, off this facade, or the slats cannot block it.
    elevation_attribute attribute name elevation Attribute to read the elevation from.
    elevation_entity entity id sun.sun Entity the sun's elevation is read from, if different from sun_entity.
    scale enum half half or full Which half of the slat's travel counts as fully closed to the sun.
    sun_entity entity id sun.sun Entity checked for whether the sun is above the horizon.
    type enum required slat_angle Picks this shape -- a tilt computed from the sun's position.

    modes¶

    Field Type Default Range Meaning
    id string required Unique mode name; must not contain a dot.
    when condition none Condition that selects this mode; omit only for the fallback mode, which must be last.

    rules¶

    Field Type Default Range Meaning
    events list of event names none Restricts this rule to state_change, manual_move or arrival events; none means every event.
    if condition none Condition that must match for this rule to apply; a rule with none always matches.
    name string Label shown in the decision trace.
    then action required The position and tilt to apply when this rule matches.

    rule then¶

    Field Type Default Range Meaning
    position position (0-100) keep keep, 0–100, or !ref Target position, or keep to leave it alone, or a named value.
    tilt tilt (0-100) keep keep, 0–100, or !ref Target tilt, or keep to leave it alone, or a named value.

    guards¶

    Field Type Default Range Meaning
    applies_to enum any any, closing, or opening Which movement this guard watches; closing means a falling position, never the slats.
    max_wait seconds or null required for defer null means no limit How long a defer may wait before on_timeout decides what happens; omitting it is a configuration error for a defer, write null for an explicitly unlimited wait.
    name string Label shown in the decision trace.
    on_timeout enum none proceed or abandon What a defer does once max_wait runs out; required for defer.
    policy enum required skip, defer, or force What this guard does when it matches -- skip the movement, delay it, or force a different action.
    recheck_every seconds 900 How often a deferred wait is re-checked, so it survives a restart; set automatically for a defer that omits it.
    stage enum output input or output Whether this guard drops the target before the decision, or overrides the decided action after.
    targets list of blind or zone ids none What this guard covers; none means every blind.
    then action none The action a force guard imposes; required for force.
    when condition none Condition that must match for this guard to apply; one with none always applies.

    manual_detection¶

    Field Type Default Range Meaning
    hold bool false Leave a blind a person moved alone until its own target changes.
    ignore_while_on list of entity ids none Entities that are on only while an automated mover is running, so their movements are not a person's.
