# Documentation Site and In-UI Help Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish a MkDocs Material site for Cover Logic and make every config-flow step and repair issue link into it with short, one-sentence field help.

**Architecture:** Site sources live in `docs/site/` (MkDocs `docs_dir`), built strictly in CI and deployed to GitHub Pages from `main`. The configuration reference is rendered from a hand-maintained `fields.yaml` that tests pin to the parser's `_*_KEYS` sets and defaults. In the integration, one helper `docs_placeholders()` supplies `{docs_url}` to every flow form/menu and repair issue; AST tests enforce that no call site forgets it.

**Tech Stack:** MkDocs + mkdocs-material 9.7 (Mermaid via `pymdownx.superfences`), PyYAML, pytest, `ast`.

**Spec:** `docs/superpowers/specs/2026-10-15-docs-site-design.md`

## Global Constraints

- Worktree `/config/dev/_wt-docs`, branch `docs/site` (from `deploy/2026-09-18`). Never work in `/config/dev/cover-logic` directly.
- All repo text (docs, code, comments, commits) in English. `translations/sk.json` stays Slovak.
- Commits: no `Co-Authored-By` line, no session links. Author email is already `admin@gameboosting.top`.
- Comments: one line, say what and why.
- Pages URL: `https://peterlinuxoss.github.io/ha-cover-logic` — the single constant `DOCS_URL` in `const.py`.
- `data_description` ≤ 150 chars; step/issue `description` ≤ 300 chars (excluding the trailing Learn-more link).
- `en.json` stays byte-identical to `strings.json`.
- Links from the site to files outside `docs/site/` (MODELS.md, rationale.md, CONTRIBUTING.md) are absolute GitHub URLs, otherwise `--strict` fails.
- Nothing is pushed, no PR is opened and Pages is not enabled within this plan.
- Fast suite: `python3 -m pytest tests/ -q --ignore=tests/parity`. HA suite: `.venv/bin/python -m pytest tests/ha -q` (venv as in `CONTRIBUTING.md`; if absent in the worktree, symlink `/config/dev/cover-logic/.venv`).

import ast
from pathlib import Path

from cover_logic.const import DOCS_URL
from cover_logic.docs_link import docs_placeholders

_COMPONENT = Path(__file__).parent.parent / "custom_components" / "cover_logic"
_FLOW_MODULES = ("config_flow.py", "options_flow.py", "subentry_flow.py")


def test_docs_placeholders_merges_extra():
    assert docs_placeholders({"blind": "cover.x"}) == {"docs_url": DOCS_URL, "blind": "cover.x"}
    assert docs_placeholders() == {"docs_url": DOCS_URL}


def _calls(path, names):
    tree = ast.parse(path.read_text(encoding="utf-8"))
    for node in ast.walk(tree):
        if isinstance(node, ast.Call):
            func = node.func
            name = func.attr if isinstance(func, ast.Attribute) else getattr(func, "id", None)
            if name in names:
                yield node


def _passes_docs(call, keyword):
    for kw in call.keywords:
        if kw.arg == keyword:
            v = kw.value
            return isinstance(v, ast.Call) and getattr(v.func, "id", None) == "docs_placeholders"
    return False


def test_every_flow_screen_supplies_docs_url():
    missing = [
        f"{mod}:{call.lineno}"
        for mod in _FLOW_MODULES
        for call in _calls(_COMPONENT / mod, {"async_show_form", "async_show_menu"})
        if not _passes_docs(call, "description_placeholders")
    ]
    assert not missing, missing


def test_every_repair_issue_supplies_docs_url():
    calls = list(_calls(_COMPONENT / "__init__.py", {"async_create_issue"}))
    assert len(calls) == 4
    missing = [c.lineno for c in calls if not _passes_docs(c, "translation_placeholders")]
    assert not missing, missing

```python
"""Placeholders shared by every flow screen and repair issue."""

from collections.abc import Mapping

from .const import DOCS_URL


def docs_placeholders(extra: Mapping[str, str] | None = None) -> dict[str, str]:
    """Return `extra` plus `docs_url`, for `description_placeholders`/`translation_placeholders`."""
    return {"docs_url": DOCS_URL, **(extra or {})}
```
At each call site: `description_placeholders=X` → `description_placeholders=docs_placeholders(X)`; where absent, add `description_placeholders=docs_placeholders()`. Variables that may be `None` (e.g. `config_flow.py:456`, `subentry_flow.py:508`) pass through unchanged — the helper handles `None`. Same for the four `translation_placeholders=`.

```python
"""Render docs/site/reference/fields.yaml into configuration.md."""

from pathlib import Path

import yaml

_ROOT = Path(__file__).parent.parent
_SRC = _ROOT / "docs/site/reference/fields.yaml"
_OUT = _ROOT / "docs/site/reference/configuration.md"
_TITLES = {
    "blinds": "blinds", "zones": "zones", "values_entity": "values (entity)",
    "values_slat_angle": "values (type: slat_angle)", "modes": "modes", "rules": "rules",
    "action": "rule `then`", "guards": "guards", "manual_detection": "manual_detection",
}
_HEADER = "# Configuration reference\n\n<!-- Generated by scripts/gen_reference.py. Do not edit. -->\n"


def _cell(value) -> str:
    return "" if value is None else str(value).lower() if isinstance(value, bool) else str(value)


def render(fields: dict) -> str:
    parts = [_HEADER]
    for section, title in _TITLES.items():
        parts.append(f"\n## {title}\n\n| Field | Type | Default | Range | Meaning |\n|---|---|---|---|---|\n")
        for name, f in sorted(fields[section].items()):
            parts.append(
                f"| `{name}` | {_cell(f.get('type'))} | {_cell(f.get('default'))} "
                f"| {_cell(f.get('range'))} | {_cell(f.get('help'))} |\n"
            )
    return "".join(parts)


if __name__ == "__main__":
    _OUT.write_text(render(yaml.safe_load(_SRC.read_text())), encoding="utf-8")
```
